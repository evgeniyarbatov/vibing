# Roadmap

## Why keep going

This is pure leverage disguised as a small tool: mic → whisper → ollama → clipboard, local, no cloud. Every other repo in this portfolio that currently demands typed notes at a keyboard ([private], [private], [private]) is a candidate to go through this pipe instead. The existing roadmap already has this right — "voice → text you can actually use" is the whole point, and everything else is downstream.

## What it opens up

Once the README/hotkey drift (already flagged as the #1 item) is fixed and the loop is genuinely dependable, this stops being "a way to transcribe" and becomes the front door for capturing *any* of this portfolio's personal-archive projects hands-free, mid-activity — dictating a waypoint memory while running, not typing it afterward.

## Capability this builds

Shipping a small, local-first tool reliable enough that you actually reach for it daily — the bar here is usage, not feature count, which is a different (harder) discipline than most of this portfolio's one-off analysis scripts.
